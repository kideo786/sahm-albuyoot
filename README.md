# 🏠 سهم البيوت - Sahm AlBuyoot

تطبيق متخصص في الديكورات والأثاث وخدمات البناء والمقاولين وإصلاح مشاكل البيوت

## 📋 المميزات

✨ **نظام المتاجر المتعددة** - متاجر متخصصة في كل فئة
✨ **البحث والفلترة المتقدمة** - جد ما تبحث عنه بسرعة
✨ **نظام التقييمات والتعليقات** - اعرف آراء العملاء الآخرين
✨ **الدعم الفني** - تواصل مباشر مع البائعين
✨ **نظام الطلبات والدفع** - دفع آمن ومتعدد الطرق
✨ **تتبع الطلبات** - اعرف حالة طلبك بشكل فوري
✨ **نظام الرغبات والمفضلة** - احفظ المنتجات المفضلة
✨ **العروض والخصومات** - احصل على أفضل الأسعار

## 🚀 التقنيات المستخدمة

### Backend
- Node.js + Express.js
- MongoDB
- JWT للمصادقة
- Stripe للدفع
- Cloudinary للصور

### Frontend
- React 18
- Redux Toolkit
- Tailwind CSS
- Vite
- React Router

## 📦 التثبيت

### المتطلبات
- Node.js v16+
- MongoDB

### خطوات التثبيت

```bash
# استنساخ المشروع
git clone https://github.com/kideo786/sahm-albuyoot.git
cd sahm-albuyoot

# تثبيت المتغيرات البيئية
cp .env.example .env

# تثبيت الحزم
npm install

# تشغيل الخادم
npm run server

# في نافذة أخرى - ��شغيل الواجهة
cd client
npm run dev
```

## 📱 الفئات الرئيسية

1. **الأثاث** - غرف، مكاتب، ديكور داخلي
2. **الديكورات** - الديكورات المنزلية والجدران
3. **مواد البناء** - الحديد، الرمل، الإسمنت، وغيره
4. **المقاولين** - خدمات الحفريات والبناء والتشطيب
5. **إصلاح المشاكل** - صيانة، تسريب مياه، كهرباء، سباكة

## 👨‍💼 أنواع المستخدمين

- **عميل عادي** - يشتري المنتجات والخدمات
- **بائع** - ينشئ متجره ويبيع المنتجات
- **مقاول/حرفي** - يقدم خدمات البناء والإصلاح
- **إداري** - إدارة النظام والموافقات
